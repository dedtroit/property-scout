# Property Scout
Hourly distressed residential listing scanner for seven Sacramento-area cities. Run `pip install -r requirements.txt` and `python app.py`, then open http://localhost:8000. Deploy the Dockerfile on Railway as a single instance. Configure SIMPLYRETS_USER and SIMPLYRETS_PASSWORD with an authorized real MLS feed (not demo credentials). Optional AUTHORIZED_FEEDS is a comma-separated set of authorized JSON-array or CSV URLs. Feed records need city, state, price, property_type, status, address, distress_type or description, optional financing, photos (JSON array or one CSV URL), listing_url. Only fetch sources you have permission to access. County and government sites are manual links until authorized machine-readable feeds are configured. No live data is bundled; financing is heuristic, not approval. Listing links fall back to address search. In-memory cache is lost on restart. The dashboard is unauthenticated; keep it private or add access control before public deployment. API provider parameters and real data access need live verification. The server is intended for a private prototype, not production traffic.
